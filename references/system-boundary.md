# 分层与现有系统边界

## 权威位置

真实财务事实仍属于用户自己的 PRIVATE_SYNC 数据目录；通用 Skill、代码和合成测试属于本 Git 仓库。个人账户映射、人物语义、已确认逐笔更正不能混入通用代码。两层有意分开，不用粗暴镜像“统一”。

## 提炼关系

- 原家庭记账 Skill 的通用规则 → SKILL.md、workflow.md。
- 已有覆盖/闭月门禁 → scripts/coverage_gate.py；去掉固定成员身份，补充强制导入状态哈希。
- 已知招行 PDF 文本解析 → scripts/parse_cmb.py；删除历史默认文件，显式输入输出，禁止覆盖不同内容。
- 多来源一对一去重原则 → scripts/ledger.py 的通用资金账户/owner/币种匹配，不带任何真实冻结批次。
- 私人分类器/成员专用月度 staging/历史合并 → 继续只留在私有数据侧。本包使用显式复核的标准行生成候选，不移植个人例外。
- 原件登记、不可变备注、月报验证 → 在独立包中提供不依赖固定家庭路径的实现。
- Fava/Dashboard → 私人定制项目保留独立。本版通过正常依赖安装上游Fava，通用适配只读取经验证的明确月份候选快照，醒目标记候选/待核/非正式；不成为另一份交易事实源，不修改生产。

## 发布到生产

本包只创建候选和报告。若要接入现有系统，先用新候选目录验证，保护旧账本/报告哈希，单独审核语义差异，再由唯一主写者使用原系统发布入口。不要把候选文件直接拷到正式月份目录。单机锁不等于跨机分布式锁。

## 保留的能力限制

已提供Fava核心图表、中文候选状态入口和独立虚构演示；没有复制私人批次适配器、资金持仓分析、完整 Dashboard UI 或原系统环境安装器。此举是避免重复事实源和泄露，而不是声称这些功能已经迁移。要扩展时先定义支持格式和合成失败样例，再增加适配器。
