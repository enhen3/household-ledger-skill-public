# 隐私与运行时数据流

## 本地脚本

ledger.py、parse_cmb.py、review.py、reconcile.py 读取显式指定文件，在私人目录写原件登记、标准行、备注、规则、候选和月报，没有模型 API 或网络上传功能。安装依赖会连接包源；维护发布器连接 GitHub，不能称全程离线。

可能处理的字段：日期时间、金额币种、银行余额、支付方式、交易号、商户/交易对方、商品说明、交易状态、成员和账户代号、来源路径/哈希/行号，以及补充用途。输出不自动匿名化。

## 云端 Agent

Agent 读取文件、展示工具结果或把异常日志带入上下文时，对应字段可能发往宿主配置的模型提供商、API 中转服务及日志系统。本包无法保证具体提供商、保留期、训练用途或传输地域；需检查实际宿主配置，未知则说明未知，不输出凭据。

即使原件未进 Git，片段、商户、交易号、用途和私人路径也可能通过上下文离开本机。错误优先输出类型、行号与必要局部标识；复制日志求助前人工审阅，避免原始文件和完整异常追踪。

## 运行方式选择

- 合成演示：云端 Agent 只读本仓库，运行 demo.py / first_run.py，不提供真实文件。
- 本地 CLI：本地终端执行，审批和报表本地查看，不把真实文件及工具输出贴回云端。安装依赖后，账务 CLI 可不连接网络。
- 本地模型：须确认宿主推理、遥测、日志与同步均符合本地要求；本包没有一键关闭所有宿主云传输的开关。
- 云端最小字段：先本地形成必要月份、金额、随机交易标识和用途问题摘录，避免账号、完整对方名称、余额、交易号及路径。仍会传输选中字段，最小化不等于匿名。

## 仓库与拟分享包

允许通用代码、合成示例、依赖、测试和不含私人信息的验收记录。禁止真实账单/账本/报表/备注、家庭身份、账户映射、私人规则、密钥密码、真实截图和敏感本地路径；PRIVATE 仓库也不例外。

发布采用 release-files.json 白名单；逐个人工审阅新增文件。检查工作树、暂存区、拟分享包和可达 Git 历史。自动模式检查不能证明绝对无泄露；测试成员、商户和账户须标注为虚构。

可疑内容只报告文件/提交位置和类型，不复制秘密。不得自行改凭据、删改或重写历史、强推、公开仓库或送到公开扫描平台。审阅范围限本仓库及拟分享材料，不扫描整份私人财务目录。
